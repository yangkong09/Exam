# Экзаменационная работа

Дисциплина: Анализ данных и искусственный интеллект  
Тема проекта: анализ и классификация клиентов на основе подготовленного датасета.

## Файлы

- `exam_customer_answer.docx` — готовые ответы на теоретические вопросы и практические выводы.
- `exam_customer_practice_executed.ipynb` — практическая часть в Jupyter Notebook.
- `customers_final_dataset.csv` — подготовленный датасет.
- `presentation_text.md` — текст для презентации.

## Датасет

Используется подготовленный файл `customers_final_dataset.csv`.
Размер датасета: 10000 строк и 57 столбцов.
Целевая переменная: `is_recent_subscriber`.

## Используемые библиотеки

- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Краткий результат

Для практической части использована модель Logistic Regression. Также для анализа важности признаков применена модель Random Forest Classifier.
Accuracy на тестовой выборке: 0.5100.
